# pure (view as [web page](https://pure.microprediction.org/))

Twelve branches of pure mathematics, each declared useless — by a named critic, or by decades of
being simply ignored — and the receipts showing what each one became. A companion to
[`schur`](https://schur.microprediction.org/) in the same format: an interactive literature map,
a timeline, and a fully sourced ledger of cases.

**The claim being tested:** G. H. Hardy's *A Mathematician's Apology* (1940), which states three
times that number theory — and, in passing, relativity — will never be useful or warlike. Both of
Hardy's own examples were wrong within a lifetime: number theory became RSA cryptography (1977);
relativity became the correction every GPS satellite needs to stay accurate.

- [Introduction](https://pure.microprediction.org/intro.html) — the Hardy problem, in full.
- [The Ledger](https://pure.microprediction.org/ledger.html) — all twelve cases, receipts included.
- [Map](https://pure.microprediction.org/map.html) — an interactive graph linking theorem to application.
- [Timeline](https://pure.microprediction.org/timeline.html) — the dismissal-to-application gap, by field.
- [Sources](https://pure.microprediction.org/sources.html) — full citations.

Corrections, tighter citations, and additional cases are welcome via issue or PR.
